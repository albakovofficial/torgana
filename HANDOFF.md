# Торгана — передача проекта разработчику

Документ собран по итогам рабочего чата с Claude (6 ноября 2026). Здесь всё, что решено, сделано и осталось сделать.

## 1. Идея и позиционирование

- **Торгана** — универсальная площадка объявлений, прямой конкурент Авито: «как Авито, только честно».
- Решения владельца: **все категории сразу**, **вся Россия сразу** (не один город), дизайн **минималистичный и премиальный, белый фон**.
- Главные отличия от Авито:
  1. Частным лицам бесплатно и без лимитов; бизнес платит фиксированную подписку (без аукциона ставок).
  2. Модерация с объяснением: каждое отклонение — с причиной, апелляцию рассматривает человек.
  3. Честная выдача: платное продвижение ограничено и помечено (на будущее).
  4. ИИ: объявление по фото, поиск обычными словами, подсказка цены.
  5. Защита от мошенников в чате; безопасная сделка (после подключения оплаты).
- Плацдарм для холодного старта: наполнение каталога бизнесом через фид, совместимый с автозагрузкой Авито (не реализовано).

## 4. Код (этот репозиторий)

GitHub: `albakovofficial/torgana`, ветка `main`.

- Node.js 22+, встроенная SQLite (`node:sqlite`), **без npm-зависимостей**. Запуск: `npm start`.
- `server.js` — HTTP-сервер и все API; `lib/` — БД, авторизация (scrypt + httpOnly-cookie), поиск, ИИ, константы (категории, города).
- `public/` — одностраничный клиент (`assets/app.js`, `assets/app.css`), без фреймворков.
- Реализовано: регистрация/вход, объявления (до 10 фото, сжатие в браузере), поиск обычными словами («коляска до 10 000 с доставкой в Казани»), фильтры, оценка цены по рынку, избранное, чат с предупреждением о мошенниках, личный кабинет, публичный профиль, модерация с причиной и апелляцией, блокировка авторов, статистика, ИИ-заполнение по фото (только при `ANTHROPIC_API_KEY`), адаптив с нижним меню на телефоне, базовые меры безопасности (проверка Origin, rate limit, проверка изображений, CSP).
- Тесты: сквозная проверка API (31 сценарий) проходила полностью; скрипт тестов в репозиторий не входил — при желании восстановить по README.
- `scripts/seed-demo.js` — тестовые объявления, **только локально**.

### Как завершить установку (по SSH под root)
```bash
mkdir -p /root/.ssh
printf 'Host github.com\n IdentityFile /root/dk\n StrictHostKeyChecking accept-new\n' > /root/.ssh/config
cp /root/dk /root/deploy_key && cp /root/dk.pub /root/deploy_key.pub
git clone git@github.com:albakovofficial/torgana.git /root/t
bash /root/t/deploy/install.sh torgana.ru albakovofficial@mail.ru
```
`deploy/install.sh` ставит Node.js 22, nginx, ufw, certbot; создаёт пользователя `torgana`, кладёт сайт в `/var/www/torgana`, данные в `/var/lib/torgana`, пишет `.env`, поднимает systemd-службу, выпускает HTTPS (если DNS уже указывает на сервер) и включает:
- **автообновление с GitHub каждые 30 секунд** (`torgana-update.timer` → `deploy/update.sh`): при новом коммите в `main` — `git reset --hard`, перезапуск, проверка здоровья и **автооткат** на прошлую версию, если сайт не поднялся;
- ежедневный бэкап БД в 04:00 (14 дней хранения).

Важно: всё, что попадает в `main`, через ~30 секунд оказывается на боевом сайте. Рекомендуется работать в отдельных ветках и сливать в `main` только проверенное.

После установки: зарегистрироваться на сайте с `albakovofficial@mail.ru` — появится раздел «Модерация». В `/var/www/torgana/.env` заполнить `SUPPORT_EMAIL`, при желании `ANTHROPIC_API_KEY`, затем `systemctl restart torgana`.
